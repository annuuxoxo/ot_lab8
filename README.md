# Assignment 8 — Optimize Anything

Optimization Techniques lab: ten experiment tracks (A–J) built with AI-assisted (vibe) coding.
See `plan.md` for the schedule and scope.

## Setup

```bash
brew install python@3.12 qemu riscv64-elf-gcc   # macOS
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## How to run each track

| Track | Command | Output |
|---|---|---|
| A — Continuous optimization | `python trackA_continuous/run.py` | `results/trackA_continuous/` |
| B — Discrete optimization | `python trackB_discrete/run.py` | `results/trackB_discrete/` |
| C — Quantum optimization | `python trackC_quantum_opt/run.py` | `results/trackC_quantum_opt/` |
| D — Submodular / parallel / distributed | `python trackD_submodular_parallel_distributed/run.py` | `results/trackD_submodular_parallel_distributed/` |
| E — Case study | `python trackE_case_study/run.py` | `results/trackE_case_study/` |
| F — Compiler | `python trackF_compiler/run.py` | `results/trackF_compiler/` |
| G — xv6 | see `trackG_xv6/README.md` | `results/trackG_xv6/` |
| H — DBMS | `python trackH_dbms/run.py` | `results/trackH_dbms/` |
| I — Quantum algorithms / QML | `python trackI_quantum_algos_qml/run.py` | `results/trackI_quantum_algos_qml/` |
| J — Software engineering | `python trackJ_software_eng/run.py` | `results/trackJ_software_eng/` |

Tests: `pytest`

## Hardware used for all measurements

- Apple M4 (10 cores: 4 performance + 6 efficiency), 16 GB RAM
- macOS 26.6.2
- No GPU or quantum hardware; quantum results are from simulators.
